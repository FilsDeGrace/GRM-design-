# GameLedger: UX Pilot pack (v2)

GameLedger is a football app with two modes: Markets (named IN-90 Football, live prediction markets) and Tips (an X-like social platform for tipsters, plus a prediction model called GRM). The references are trading and prediction apps used only for layout and clarity patterns.

Files:
1. `01_DESIGN_BRIEF.md`: product, community layer, design direction, theme, type, rules. Use as the project document, or paste it first.
2. `02_SCREEN_PROMPTS.md`: a Global Context prompt, then one prompt per screen (S1 to S29). Paste the Global Context first, then one screen at a time.
3. `03_TOKENS.json`: the current theme. `DESIGN.md`: the same system in design-system form, with component rules.
4. `references/`: screenshots and a README on what to borrow from each.

Working order:
1. Generate ONE hero screen first: S1, the Markets Live list. Iterate until approved. Everything else copies it.
2. Then S2 (stake ticket) and S3 (card states), then the rest in order. Do not generate all at once.
3. Export each screen as soon as you like it.

Not in this round: Bet Prop or any funded-capital product. Community chat is designed only as the IN-90 Room (S23).

Rules: take structure, density and behavior from the references. Do not copy logos, names, icons, illustrations, wording or exact colors from any other product.
